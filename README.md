
# Connect-10

## Overview
Connect-10 is a Python-based implementation of a classic board game, similar to Connect-4, but with extended rules or variations. The game involves token placement and checking win conditions based on alignments of tokens.

## Features
- **Board Representation**: `board.py` handles the game's grid logic.
- **Token Insertion**: `inset_token.py` manages player inputs and token placement on the board.
- **Color Management**: `colour.py` defines token colors and visual aspects of the game.

## Setup Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/shlok12343/connect-10
   ```
2. Install dependencies (if any).
3. Run the game:
   ```bash
   python main.py
   ```

## Files
- **`main.py`**: Entry point of the game.
- **`board.py`**: Handles the game board structure and functions.
- **`inset_token.py`**: Logic for placing tokens on the board.
- **`colour.py`**: Defines colors for the game.
